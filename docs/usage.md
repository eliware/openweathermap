# Usage

Install `@eliware/openweathermap` with npm. Set `OWM_API_KEY`, or pass `apiKey` to a method. Import `getCurrent`, `get24hForecast`, or `getSun` from the package.

Pass latitude and longitude as numbers. Set `units` to `C`, `F`, `K`, `metric`, `imperial`, or `standard`. The default is Celsius.
